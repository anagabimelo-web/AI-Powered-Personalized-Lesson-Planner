# AI-Powered-Personalized-Lesson-Planner
An AI-assisted workflow for creating personalized English lessons based on student needs, goals, interests, and learning challenges.
## Why I Built This

I built this project based on a real challenge in my work as a private English teacher. I work with students who have different levels, goals, interests, and learning challenges, so lesson planning often requires adapting the same learning objective in different ways.

I started experimenting with AI to see whether it could help me reduce repetitive planning work while keeping lessons personalized.

This project is a small experiment in using AI as a support tool: the AI generates possibilities, while the teacher provides the context, reviews the suggestions, and makes the final decisions.

The project also helped me explore a broader question: how can AI support people in making better decisions and creating more personalized experiences without replacing human judgment?
